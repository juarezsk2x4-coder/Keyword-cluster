# Keyword-cluster

The name is a leftover from whatever this repo was originally created for —
it doesn't match what's actually here.

## Meal-planning + habit-tracker app (`app/`)

A Next.js 15 web app for meal planning, habit logging, and AI-assisted plan
generation. See [`app/README.md`](app/README.md) for what it does,
[`DEPLOY.md`](DEPLOY.md) for how to deploy it, and [`SECURITY.md`](SECURITY.md)
for the secret-handling model.

Supporting content for the app lives alongside it at the repo root:

- `data/` — profile YAMLs, household logistics, recipes the app reads
- `agents/` — design docs for the app's UX patterns
- `wife/` — a plain-language, non-technical onboarding template
